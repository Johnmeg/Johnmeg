Probador de data actions

Genera datos aleatorios en una versión de pruebas, ejecuta el data action (a través de una multi action) y compara el resultado de SAC con el valor esperado.

Inicie sesión con su usuario de SAP Analytics Cloud

Las pruebas se ejecutan con sus propios permisos de SAC: carga de datos en el modelo y ejecución de la multi action.

1. Caso de prueba

Definición
Los cambios se guardan en este navegador.
Guía rápida de la definición
  • modelo: ID del modelo (de la URL del Modeler). multiAction: ID de la multi action que ejecuta el data action, formato <paquete>:<ID>.
  • version: versión de pruebas; antes de cargar se borran sus datos en los periodos del caso. parametros: los parameterValues de la multi action; {{version}} se reemplaza por la versión.
  • entradas: datos aleatorios entre min y max. fijo = miembros fijos; variar = lista de miembros, {"aleatorio": 3, "filtro": {"PROPIEDAD": "Y"}} o "@ENTRADA".
  • esperado: celdas que el data action debe escribir y su formula: v('PRECIO') * v('UNIDADES'), sum('GASTO') * v('KM') / sum('KM'), -v('GASTO'), round(x, 2), c.Date.
  • tolerancia: diferencia permitida (por defecto 0,01).
