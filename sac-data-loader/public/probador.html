2. Parámetros del data action

Los parámetros que la multi action le pasa al data action (el ID debe ser el mismo de la multi action). Un parámetro de tipo miembro también se puede usar en los datos de prueba con "$ID".

3. Datos de prueba y resultado esperado

Entradas aleatorias, resultados esperados y sus fórmulas. Los campos de los pasos 1 y 2 se reflejan aquí y viceversa.

Guía rápida
  • entradas: datos aleatorios entre min y max. fijo = miembros fijos; variar = lista de miembros, {"aleatorio": 3, "filtro": {"PROPIEDAD": "Y"}}, "@ENTRADA" o "$PARAMETRO".
  • esperado: celdas que el data action debe escribir y su formula: v('PRECIO') * v('UNIDADES'), sum('GASTO') * v('KM') / sum('KM'), -v('GASTO'), round(x, 2), c.Date.
  • comun: miembros fijos para todas las celdas (admite "$PARAMETRO").
